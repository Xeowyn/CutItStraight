CUT IT STRAIGHT - play-test copy
================================

1. Unzip this whole folder somewhere (Desktop is fine).
   Don't run it from inside the zip - extract it first.

2. Double-click  "Start Game.bat"

   A black window opens and the game opens in your browser at
   http://localhost:8936/   (if that port is busy it uses the next one -
   the black window shows the exact address).

   Keep the black window open while you play. Close it when you're done.
   To play again later, just double-click "Start Game.bat" again.

   If Windows says "Windows protected your PC": click "More info",
   then "Run anyway".

   Mac: double-click "Start Game (Mac).command" instead
   (first time: right-click it > Open).

BACKUP: if the launcher won't run, double-click CutItStraight.html -
it's the whole game in one file and needs no server.

Controls: drag left/right (mouse or finger) to steer the board so the blade
follows the glowing line. Tap / click / Space to jump the saw across gaps.
F11 = full screen.

Progress saves in the browser on this computer. This test copy has no ads.
